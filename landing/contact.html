Helpful things to include in a bug report

  • Which tool you were using (Sequence, Tree, Matrix, Sanger…).
  • What you did right before the problem, and what you expected.
  • The kind of file (e.g. FASTA, Newick, distance matrix) — no need to send sensitive data.
  • Your browser and, if visible, any error message shown on screen.
